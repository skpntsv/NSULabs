# Лабораторные работы

## [1. Базовые операции над структурами данных](./lab1)

В рамках лабораторной работы рассматриваются:
- генерация строк фиксированной длины с ограничениями;
- рекурсивные и хвосторекурсивные алгоритмы;
- реализация `map` и `filter` через `reduce`;
- использование функционалов `map` / `reduce` / `filter` для решения задачи.

---

## [2. Численное интегрирование](./lab2)

В лабораторной работе реализуется:
- численное интегрирование функции одной переменной;
- метод трапеций с постоянным шагом;
- оптимизация вычислений с помощью мемоизации;
- оптимизация с использованием бесконечных последовательностей частичных результатов.

---

## [3. Параллельная обработка последовательностей](./lab3)

Основные задачи:
- реализация параллельного варианта `filter` с использованием `future`;
- разбиение последовательностей на блоки вручную;
- реализация ленивого параллельного `filter`;
- работа с бесконечными потоками данных;
- сравнение производительности с последовательной реализацией.

---

## [4. Символьные булевы выражения и ДНФ](./lab4)

В лабораторной работе реализуется:
- представление символьных булевых выражений;
- операции конъюнкции, дизъюнкции, отрицания и импликации;
- подстановка значений переменных;
- приведение выражений к дизъюнктивной нормальной форме (ДНФ);
- расширяемая архитектура для добавления новых логических операций;
- покрытие кода тестами и документирование API.
